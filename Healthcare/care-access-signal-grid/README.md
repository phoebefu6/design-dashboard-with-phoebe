# Care Access Signal Grid

An interactive healthcare access dashboard concept built with Python-generated mock data and a React frontend.

## Live Dashboard

**[Open the interactive dashboard](https://phoebefu6.github.io/design-dashboard-with-phoebe/Healthcare/care-access-signal-grid/)**

It runs directly in a browser through GitHub Pages. No installation or GitHub account is required.

## What It Monitors

- Provider access score
- Disparity risk
- Appointment speed
- Insurance coverage
- Language access
- Affordability
- Digital readiness
- Local demand load
- Uninsured share and no-show risk context

## Interactions

- Filter providers by region and provider type.
- Sort by disparity risk, access score, demand load, or monthly visits.
- Search providers by name.
- Select any signal tile to inspect provider-level metrics.
- Use the input layer to paste available field names and receive a dashboard/data-prep recommendation.
- Open the data-prep guide for a reproducible real-data mapping.

## Data

The dataset is synthetic and generated by:

```bash
python3 Healthcare/care-access-signal-grid/scripts/generate_mock_data.py
```

Output:

```text
Healthcare/care-access-signal-grid/data/providers.json
```

## Technology

- Python for data generation
- React through CDN for interaction
- SVG for custom signal glyphs
- CSS for responsive layout, motion, and visual system
- GitHub Pages for static hosting

## Run Locally

From the repository root:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080/Healthcare/care-access-signal-grid/
```
