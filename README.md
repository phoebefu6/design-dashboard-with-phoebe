# Design Dashboard with Phoebe

A portfolio of dashboard design work by Phoebe Fu, focused on turning business questions into polished, usable data products.

This repository showcases dashboard concepts I designed and built across industries. Each project is meant to demonstrate taste, information hierarchy, interaction design, metric thinking, frontend craft, and the ability to make complex data feel clear.

## Design Range

The work in this portfolio covers:

- Executive dashboards for fast scanning and confident decision-making.
- Operational dashboards for monitoring live work, exceptions, and risk.
- Analytical dashboards that reveal patterns across segments, people, providers, campaigns, or locations.
- Interactive tools that combine dashboard UI with workflow, recommendations, or data-prep guidance.
- Custom visual systems, including SVG marks, responsive layouts, motion, and domain-specific metric models.

## What I Care About

- Clear hierarchy before decoration.
- Metrics that match the user’s decision, not just available data.
- Interfaces that make comparison, filtering, diagnosis, and follow-up action easy.
- Visual systems that fit the industry and problem.
- Responsive layouts that still feel designed on smaller screens.
- Honest data notes when examples use synthetic or mock data.
